Publish External / Other Examination Results

Upload an Excel result sheet. The rows will be imported into the Firebase database and candidates can later search their result using their mobile number.

1. Prepare the Excel file

Use the official template. One row = one candidate result. Mobile Number is mandatory because it is the search key.

Required columns: Publication ID, Exam Name, Exam Date, Roll No, Mobile Number, Student Name, Class / Designation, School / Place of Posting, then for each subject: Subject Marks, Subject Grade, Subject Rank, followed by Total Marks, Obtained Marks, Percentage, Overall Grade, Overall Rank, Result / Status, Remarks.

2. Upload Result Excel

If a Publication ID already exists, the system will ask before replacing that published result set. Replacement removes the previous rows for that publication and imports the new Excel rows.

Select an Excel file to begin.
