SECURITY LIMITATIONS (IMPORTANT)
- Firebase rules currently allow authenticated reads of academicOlympiadTests, which includes the question answer key. A technically skilled participant may inspect the answer key in browser/network tools. Client-side scoring is therefore practice-grade, not secure high-stakes examination scoring.
- The participant mobile number is self-entered and is not OTP-verified. The private roster check is an access filter, not strong identity verification.
- Room codes should not be treated as passwords. For confidential exams and tamper-resistant scoring, use a trusted server-side scoring backend and stronger identity verification.
- Anonymous Authentication must be enabled in Firebase Authentication for participant access.
