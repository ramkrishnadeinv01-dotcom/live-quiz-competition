ACCESS POLICY:

DEPLOYMENT:
1. Back up your current GitHub repository and Firebase Realtime Database/Storage rules.
2. Upload the website files from this ZIP to the repository root, preserving existing files.
3. Firebase Console > Realtime Database > Rules: merge the academicMaterials and academicOlympiadTests rules from database.rules.json into the currently deployed rules. Do not blindly replace unrelated rules.
4. Firebase Console > Storage > Rules: merge the academic-materials match block from storage.rules into the currently deployed Storage rules. Do not replace unrelated Storage rules.
5. Keep Email/Password authentication enabled for the administrator. Participant anonymous authentication can remain enabled.

SECURITY LIMITATION — PRACTICE TESTS:
- This module is a practice-test feature, not a secure/high-stakes examination system.
- Correct answers are included in the test data read by the participant browser for automatic client-side scoring. A determined user can inspect browser data.
- Firebase Spark has no trusted server-side scoring through Cloud Functions. Do not use these mock tests for confidential assessments or prizes requiring tamper-proof scoring.
- To make answer keys confidential on Spark, automatic scoring must be removed or answers must be checked manually by the administrator. A trusted backend is required for tamper-resistant automatic scoring.
